Objective:
To analyze multiple seasons of IPL data to answer key strategic questions, such as:
- What factors have held RCB back over the years?
- Who are the most consistent players across seasons and venues?
- How do toss decisions, venues, and match situations affect outcomes?
- How can auction planning be improved using data?

Project Highlights:
- Season-wise win/loss trends and performance comparison
- Key batting & bowling metrics: averages, strike rates, economy, wickets
- Venue-wise match impact and home vs away analysis
- Identification of dependable all-rounders and high-value auction picks
- RCB’s strengths, weaknesses, and long-term performance gaps

Tools & Technologies Used:
 MySQL - Advanced joins, subqueries, aggregations, CTEs, and window functions
 Excel - Pivot tables, visual dashboards, charts, and formatting

Key Insights Generated:
- Over-reliance on star batsmen with limited middle-order support
- Bowling unit struggled at crucial stages, especially death overs
- Toss choices significantly affected win probability in certain venues
- Only a small set of players consistently performed in both batting & bowling
- Certain venues proved beneficial for specific player styles

What This Project Taught Me:
- How to transform raw cricket data into meaningful, actionable insights
- Applying SQL for multi-stage filtering, ranking, grouping, and analysis
- Designing clear visual summaries using Excel dashboards
- Connecting sports analytics to real-world decision-making (team selection, auction planning, and performance review)
